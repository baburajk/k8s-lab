Setup Router A
==============

Step 1: Configure Network Interfaces
-------------------------------------
- LAN: `igc0` - IP: 192.168.1.1/24
- WAN: `igc1` - IP: DHCP
- Peering: `igc2` - IP: 10.1.1.1/30

Step 2: Create Firewall Rules
------------------------------
- Action: Pass
- Interface: Peering (igc2)
- Direction: In
- Protocol: TCP
- Source: Peering Network
- Destination Port: 179 (BGP)
- Description: Allow inbound BGP traffic from peer

Step 3: Configure General Settings
-----------------------------------
- Routing: Enable
- Firewall Rules: Deselect (since custom rules are created)
- Save: Press Save
